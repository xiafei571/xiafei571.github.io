## A personal blog build by jekyll

- link: https://xiafei571.github.io

## Dependencies

This project relies on the following tools, packages, and software:

### Development Tools
- [Jekyll](https://jekyllrb.com/) - Static site generator
- [Ruby](https://www.ruby-lang.org/) - Programming language (Jekyll is built with Ruby)
- [Bundler](https://bundler.io/) - Dependency management for Ruby projects

### Packages
- See `Gemfile` for a list of Ruby gems used in this project

## Installation

1. Ensure you have Ruby installed on your system.
2. Install Jekyll and Bundler:
   ```
   gem install jekyll bundler
   ```
3. Clone the repository:
   ```
   git clone https://github.com/yourusername/your-blog-repo.git
   ```
4. Navigate to the project directory:
   ```
   cd your-blog-repo
   ```
5. Install dependencies:
   ```
   bundle install
   ```

## Usage

1. To run the blog locally:
   ```
   bundle exec jekyll clean
   bundle exec jekyll serve
   ```
2. Open your browser and go to `http://localhost:4000`
