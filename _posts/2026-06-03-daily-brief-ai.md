# 每日 AI 简报 - 2026-06-03

## 今日最重要的 3 条 AI 新闻

### 1. OpenAI 扩大 Codex 场景，不只给程序员写代码
- 来源：OpenAI
- 链接：https://openai.com/index/codex-for-every-role-tool-workflow/
- 这件事是什么：OpenAI 在 6 月 2 日介绍 Codex 的新用法，重点不再只是写代码，而是让产品、运营、数据、设计等岗位也能用 Codex 做内部工具、仪表盘、材料整理和自动化流程。
- 为什么重要：这说明 coding agent 正在从“程序员助手”变成“公司内部自动化工具”。谁能把自然语言、代码和业务流程接起来，谁就更容易把 AI 落到日常工作里。
- 对我有什么影响：如果你不是全职开发，也可以开始把重复性的表格、报告、脚本和后台小工具交给 Codex 试做。关键不是学会所有代码，而是会把需求讲清楚、会验收结果。

### 2. Anthropic 扩大 Project Glasswing，用 Claude Mythos 找安全漏洞
- 来源：Anthropic
- 链接：https://www.anthropic.com/news/expanding-project-glasswing
- 这件事是什么：Anthropic 在 6 月 2 日宣布扩大 Project Glasswing，把合作范围从约 50 家机构扩到约 150 家。参与组织会用 Claude Mythos Preview 扫描关键软件漏洞，并在上线前做安全检查。
- 为什么重要：AI 正在进入网络安全的核心环节：不只是帮人写代码，也能提前发现高危漏洞、生成补丁。未来软件安全的竞争，会变成“谁能更快发现、验证和修复问题”。
- 对我有什么影响：如果你维护线上服务，安全扫描和依赖检查会越来越自动化。即使不用 Claude Mythos，也应该把 AI 辅助代码审查、漏洞扫描、补丁验证放进发布流程。

### 3. Microsoft Build 2026 推出 Agent 365 SDK 和 AI agent 安全栈
- 来源：Microsoft
- 链接：https://www.microsoft.com/en-us/security/blog/2026/06/02/microsoft-build-2026-securing-code-agents-and-models-across-the-development-lifecycle/
- 这件事是什么：Microsoft 在 Build 2026 发布面向开发者的 agent 安全能力，包括 Agent 365 SDK、可观测性、访问控制、合规控制，以及用于 agent 安全评估和控制标准化的开源项目。
- 为什么重要：企业要把 AI agent 放进生产环境，最大问题不是 demo 能不能跑，而是权限、日志、数据边界和合规怎么管。Microsoft 正在把 agent 当成新的应用层来治理。
- 对我有什么影响：做企业 AI 产品时，别只展示“agent 会做事”。客户会问它能访问什么、做错了怎么追踪、能不能审计。提前设计权限和日志，会比后补安全功能省很多麻烦。

## 今日重点关注

今天最值得重点关注的是：Microsoft Build 2026 推出的 Agent 365 SDK 和 AI agent 安全栈。
原因：AI agent 要真正进入公司系统，必须解决权限、审计和合规问题。谁能把这些基础设施做好，谁就更容易把 agent 从演示带到真实业务。
