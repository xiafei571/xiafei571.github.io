## 📄 PDF Watermark Tool

A professional PDF document watermarking tool that supports batch processing, custom watermark styles, and parameter adjustments.

**Key Features:**
- Batch PDF file processing
- Custom watermark text, font, size, and color
- Adjustable watermark transparency, angle, and position
- Real-time watermark preview
- Support for multiple page sizes
- One-click download of processed files

**Perfect for:** Document protection, branding, copyright protection, and professional PDF editing.

## 🏢 Company Matrix Generator

A rapid company matrix display page generator that automatically fetches company logos and website links, supporting custom matrix layouts.

**Key Features:**
- Automatic company logo fetching (Clearbit API)
- Generate company website links
- Custom matrix rows and columns (M×N)
- Responsive design for all screen sizes
- Edit company information
- Export HTML code

**Perfect for:** Business presentations, company showcases, portfolio displays, and professional web layouts.
